1. شنو هي أداة ECC؟

ECC (اختصاراً لنظام تحسين أداء وكلاء البرمجة) هي مشروع مفتوح المصدر من المطوّر affaan-m على GitHub. فكرتها بسيطة وقوية:

plan التخطيط←test الاختبار←implement التنفيذ←review المراجعة←verify التحقق←remember التذكّر←improve التحسين

بدل ما تعيد كتابة نفس التعليمات في كل محادثة مع الذكاء الاصطناعي، بتثبّت ECC مرة واحدة وهي بتكون جزء من طريقة شغل المساعد.

🧠 ذاكرة وتعليم مستمر
بتحفظ ملخصات الجلسات والدروس المستفادة (instincts) عشان ما تعيد نفس الغلط.
🛡️ أمان AgentShield
فحص للبرومبتات والـ hooks وإعدادات MCP والأسرار المسربة وملفات الوكلاء.
🔍 البحث أولاً
منهجية research-first: يبحث في الكود والتوثيق قبل ما يكتب سطر واحد.
🔌 تدعم 7+ أنظمة
Claude Code و Codex و Cursor و OpenCode و Gemini و Zed و Copilot وغيرها.

المصادر الرسمية فقط: مستودع github.com/affaan-m/ECC وحزم npm ‏ecc-universal و ecc-agentshield والموقع ecc.tools. أي نسخة من حتة تانية ممكن تكون فيها برمجيات خبيثة.

4. طرق التثبيت (كل الأنظمة)

المتطلبات

Node.js 18+ و Git. لـ Claude Code plugin تحتاج Claude Code 2.1+ في الـ PATH.

node --version   # لازم 18+
git --version
claude --version # لو بتستخدم Claude Code

أ) التثبيت الموجّه (الموصى به)

npx ecc-universal@2.2.3 setup
# أو لعدة أنظمة مع بعض:
npx ecc-universal@2.2.3 install --guided

ب) Claude Code (أوامر أصلية داخل الجلسة)

/plugin marketplace add https://github.com/affaan-m/ECC
/plugin install ecc@ecc

ج) Codex

codex plugin marketplace add affaan-m/ECC
codex plugin add ecc@ecc
codex plugin list --json

د) OpenCode (الطريقة الاستخدمناها عندك)

git clone https://github.com/affaan-m/ECC.git
cd ECC
npm install && npm run build:opencode
./install.sh --profile full --target opencode --enable-hooks

هـ) باقي الأنظمة

⚠️ قاعدة مهمة: اختار طريقة واحدة فقط لكل نظام. ما تدمج plugin + تثبيت يدوي كامل في نفس النظام عشان ما تتضاعف الملفات.

8. الصيانة: تحديث وفحص وإزالة

# فحص السلامة
node scripts/ecc.js doctor --target opencode
# أو من الحزمة المنشورة:
npx ecc-universal@2.2.3 doctor --target opencode

# التحديث (أعد نفس أمر التثبيت)
npx ecc-universal@2.2.3 setup

# إصلاح التثبيت
node scripts/ecc.js repair

# إزالة نظيفة (جرب أولاً بوضع المعاينة)
node scripts/ecc.js uninstall --dry-run
node scripts/ecc.js uninstall

ملفاتك الشخصية المعدّلة ما بتتمسح تلقائياً — ECC بحافظ عليها ويبلّغك بيها للمراجعة.

9. أسئلة شائعة

هل ECC مجاني؟
أيوه، المستودع مرخّص MIT ومجاني للأبد. في نسخة مدفوعة (ECC Pro عبر GitHub App) للمستودعات الخاصة بتموّل شغل المشرف الوحيد.

أثبّت في كم نظام مع بعض؟
ممكن (مثلاً Claude + Codex مع بعض)، لكن طريقة واحدة فقط لكل نظام. ما تكدّس plugin فوق manual install.

التثبيت ما ظهر لي، أعمل شنو؟
افتح جلسة جديدة وشغّل /plugin list (لـ Claude) أو doctor، وراجع ملف TROUBLESHOOTING.md في المستودع، أو افتح issue بقالب install-problem.

هل بياناتي بتترفع؟
لا. ECC ما بيرفع أي تشخيصات تلقائياً. أمر ecc feedback اختياري تماماً.
